# DSA Practice Repository

This repository contains my Data Structures and Algorithms practice work, including topic-wise questions, data structure implementations, daily semester practice, notes, and revision notebooks.

## Repository Structure

```text
.
├── topic_wise_questions/
│   └── arrays/
├── data_structure_implementations/
├── dsa_topics/
├── 3-sem_daily_questions/
├── practice_sessions/
├── extra_questions/
└── notes/
```

## Folder Overview

- `topic_wise_questions/`: Topic-based problem solving notebooks organized by sessions.
- `data_structure_implementations/`: Core data structure implementation notebooks such as linked list, queue, stack, deque, and tree.
- `dsa_topics/`: Concept-focused notebooks such as implementing one data structure using another.
- `3-sem_daily_questions/`: Daily DSA practice notebooks from Semester 3.
- `practice_sessions/`: Short revision and focused practice sessions.
- `extra_questions/`: Additional practice notebooks and extra question sets.
- `notes/`: Reference notes and quick concept summaries.

## Naming Convention

- Lowercase folder and file names
- Underscore-based naming for better readability
- Session and day based notebook names for easy tracking

## How To Navigate

1. Start with `topic_wise_questions/` for structured problem solving.
2. Use `data_structure_implementations/` for core concept revision.
3. Follow `3-sem_daily_questions/` for daily consistency tracking.
4. Open `notes/` and `practice_sessions/` when you want quick revision.

## Current Coverage

- Arrays practice sessions
- Linked list, queue, stack, deque, and tree implementations
- Stack using queue and queue using stack concepts
- Daily semester practice notebooks

This structure is designed to keep the repository clean, GitHub-friendly, and easy to maintain over time.
